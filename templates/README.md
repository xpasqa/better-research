# Working templates

Copy a template into the appropriate working location only when that stage begins. Replace `NOT YET FILLED` with real information supported by evidence. Empty tables intentionally contain no example data. Source notes, claim ledgers, decisions, and reviews follow the [provenance model](../docs/provenance.md).

| Template | Suggested working location |
|---|---|
| [Session checkpoint](session-checkpoint.md) | Issue comment and body snapshot; temporary local file if GitHub is unavailable |
| [Problem memo](problem-memo.md) | research/problem-memo.md |
| [Review protocol](review-protocol.md) | research/review-protocol.md |
| [Search log](search-log.md) | literature/searches/ |
| [Screening log](screening-log.md) | literature/screening/ |
| [Source note](source-note.md) | literature/notes/ |
| [Claim ledger](claim-ledger.md) | literature/claim-ledger.md |
| [Theory and contribution](theory-contribution.md) | research/theory-contribution.md |
| [Design matrix](design-matrix.md) | research/design-matrix.md |
| [Analysis plan](analysis-plan.md) | analysis/analysis-plan.md |
| [Ethics/data plan](ethics-data-plan.md) | research/ethics-data-plan.md |
| [Chapter plan](chapter-plan.md) | manuscript/chapter-plan.md |
| [Gate review](gate-review.md) | reviews/ |
| [Review response](review-response.md) | reviews/ |

The SRC, STUDY, CLM, RQ, DEC, and REV identifiers are local traceability conventions, not external academic standards.
