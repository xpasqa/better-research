# Disertasi Gemma

Repository ini adalah workspace resmi untuk naskah dan material riset disertasi Gemma.

## Prinsip Kerja

- `manuscript/` adalah sumber naskah kanonik dalam format Markdown.
- Perubahan substantif dilakukan melalui Issue, branch, commit, dan Pull Request.
- File sumber eksternal, draft Word, dan spreadsheet manajemen diperlakukan sebagai referensi, bukan sumber kanonik.
- Sumber akademik harus dapat diverifikasi sebelum digunakan sebagai evidence.
- Klaim yang belum memiliki dukungan sumber diberi penanda TODO, bukan diisi dengan citation atau data yang tidak terverifikasi.

## Status Awal

Repository ini disiapkan pada Agustus 2026 sebagai workspace version-controlled untuk disertasi Gemma.
