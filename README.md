# Disertasi Anif — Boilerplate Riset Doktoral

Status: **boilerplate siap; penelitian belum dimulai**. Topik, kampus, paradigma, metode, dan data belum ditetapkan. Template ini dapat digunakan ulang untuk proyek lain; ganti identitas melalui project brief.

## Mulai di sini

1. Baca [aturan agent](AGENTS.md) dan [integritas akademik](docs/academic-integrity.md).
2. Isi [project brief](research/project-brief.md), termasuk pedoman kampus dan batas penggunaan AI.
3. Gunakan [alur riset](docs/research-workflow.md) untuk memilih tahap aktif dan [kriteria mutu](docs/quality-gates.md) untuk menilai kesiapan.
4. Pilih [skill yang sesuai](docs/skills.md). Buat protokol sebelum menjalankan penelusuran terstruktur.
5. Simpan keputusan, bukti, dan batas pengetahuan. Tulis naskah berdasarkan hasil yang sudah dapat ditelusuri.

Contoh permintaan:

- “Gunakan dissertation-framing untuk memperjelas masalah berdasarkan project brief.”
- “Gunakan dissertation-evidence untuk membuat protokol review; jangan jalankan pencarian dulu.”
- “Gunakan dissertation-audit untuk menilai kesiapan proposal berdasarkan bukti yang tersedia.”

## Batas dan status

Tidak ada hasil penelitian, referensi substantif, persetujuan etik, atau klaim novelty yang sudah diisi. Penanda `BELUM DIISI` adalah pekerjaan terbuka, bukan hasil penelitian.

Standar pelaporan dipilih sesuai disiplin dan desain. APA 7 adalah pilihan sementara untuk sitasi; ketentuan resmi kampus perlu dikonfirmasi. Lihat [dasar standar dan ruang berlakunya](docs/standards.md).

Skill lokal dapat ditemukan oleh Codex yang mendukung `.agents/skills` ketika proyek dibuka dari repositori ini. Jika belum muncul, buka ulang sesi atau minta agent membaca jalur SKILL.md yang tercantum di indeks. Skill ini tidak memasang plugin, menyediakan akses basis data berbayar, atau menjalankan riset otomatis.
