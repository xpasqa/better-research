# Citation Guide Disertasi Gemma

Standar resmi adalah APA Style 7th Edition.

Setiap sumber yang digunakan dalam naskah harus sinkron di dua file:

```text
literature/references.bib
manuscript/07-references.md
```

Aturan minimum:

- Jangan membuat citation palsu.
- Jangan menebak DOI, URL, tahun, volume, issue, atau halaman.
- Bedakan sumber peer-reviewed, regulasi, laporan, dan halaman institusional.
- Jika metadata belum lengkap, beri TODO metadata.

Contoh TODO:

```markdown
<!-- TODO APA7-METADATA: verifikasi publisher/DOI/year/volume/issue/pages sebelum finalisasi -->
```
