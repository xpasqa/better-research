# Workflow Disertasi Gemma

Workflow resmi mengikuti `AGENT.md`.

Alur kerja utama:

```text
Issue -> Branch -> Edit Markdown/Data/Literature -> Commit -> Pull Request -> Review -> Revise -> Merge -> History
```

Catatan:

- Naskah kanonik berada di `manuscript/`.
- Referensi kanonik berada di `literature/references.bib`.
- Draft daftar pustaka aktif berada di `manuscript/07-references.md`.
- Catatan review dan revisi berada di `reviews/`.
- Data mentah tidak diubah langsung.
- Agent tidak boleh mengarang referensi, evidence, atau citation.
