# Style Guide Disertasi Gemma

Panduan ini mengikuti aturan umum pada `AGENT.md`.

## Markdown

- Gunakan satu heading `#` untuk judul bab.
- Gunakan `##` untuk subbab.
- Gunakan `###` untuk sub-subbab.
- Gunakan paragraf pendek, jelas, dan mudah diekspor.
- Gunakan HTML comment untuk catatan internal.

## Citation

- Standar citation: APA Style 7th Edition.
- Citation sementara hanya boleh digunakan jika metadata sumber dapat dilacak.
- Jika sumber belum jelas, gunakan TODO sumber.

Contoh:

```markdown
<!-- TODO: tambahkan sumber untuk klaim ini -->
```
