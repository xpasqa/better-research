## 1. Evidence Hierarchy

Outline ini membedakan tiga level sumber agar tidak mengubah precedent menjadi aturan formal.

### Level A — Official UI-wide requirements

Sumber utama:

- Universitas Indonesia, *Pedoman Teknis Penulisan Tugas Akhir Mahasiswa Universitas Indonesia*, Revisi 2017, disahkan dengan SK Rektor UI No. 2143/SK/R/UI/2017.
- URL resmi: https://lib.ui.ac.id/unggah/sites/default/files/panduan/Pedoman%20Teknis%20Penulisan%20Tugas%20Akhir%20Mahasiswa%20Universitas%20Indonesia.pdf

Hal yang dapat dipastikan dari pedoman resmi UI:

1. Tugas akhir mencakup skripsi, tesis, dan **disertasi**.
2. Bagian isi disampaikan dalam sejumlah bab.
3. **Pembagian bab dari pendahuluan sampai kesimpulan ditentukan oleh fakultas sesuai kebutuhan.** Karena itu tidak sah mengklaim bahwa UI-wide mewajibkan satu set subjudul tertentu untuk semua disertasi.
4. Bagian pokok mencakup **tinjauan pustaka, metode penelitian, hasil, dan pembahasan**.
5. Istilah/judul bab dan subbab dapat disesuaikan dengan kebijakan fakultas.
6. Tingkatan subbab maksimal tiga tingkat.
7. Bagian akhir memuat **Daftar Referensi** dan **Lampiran** bila ada.

Implikasi: pedoman UI mengunci struktur makro dan format, tetapi tidak mengunci secara universal nama subbab Bab 1–4 untuk semua program doktor.

## 4. Canonical UI/PPIM Baseline for Dodo

Berdasarkan Level A + precedent PPIM, arsitektur kerja yang dikunci adalah:

# BAB 1 — PENDAHULUAN

## 1.1 Latar Belakang

Fungsi:
- membangun fenomena dan research problem;
- menunjukkan empirical/theoretical tension;
- membawa pembaca dari konteks luas menuju masalah individual-level yang akan diteliti;
- menggunakan evidence secara proporsional tanpa overclaim.

## 1.2 Penelitian Terdahulu

Fungsi:
- ringkasan problem-facing mengenai state of existing evidence;
- menunjukkan studi yang paling langsung berhubungan dengan research problem;
- tidak menggantikan tinjauan kepustakaan mendalam di Bab 2.

Untuk proyek Dodo, bagian ini harus berupa synthesis singkat, bukan citation dumping.

## 1.3 Masalah dan Pertanyaan Penelitian

Fungsi:
- menyatakan research problem secara eksplisit;
- menetapkan unit/level analisis;
- memuat substantive research questions.

## 1.4 Kesenjangan Penelitian

Fungsi:
- menurunkan gap dari synthesis evidence;
- membedakan empirical, explanatory/mechanism/configuration, dan boundary-condition gap bila memang didukung;
- tidak menggunakan "few studies", "different country", atau "belum pernah menggabungkan" sebagai gap tanpa puzzle substantif.

## 1.5 Tujuan Penelitian

Fungsi:
- one-to-one alignment dengan research questions;
- tidak menambahkan tujuan yang tidak mempunyai research question.

## 1.6 Ruang Lingkup Penelitian

Fungsi:
- objek/setting;
- unit analisis;
- konstruk utama;
- batas generalisasi;
- batas level kinerja individual vs unit/organisasi.

# BAB 3 — MODEL PENELITIAN DAN PENGEMBANGAN HIPOTESIS

## 3.1 Model Penelitian

Isi:
- integrasi X1 Kepemimpinan Digital;
- X2 Lingkungan Kerja Digital;
- Z Keterikatan Personel;
- Y Kinerja Personel;
- posisi direct dan indirect paths;
- theoretical mechanism;
- diagram model.

## 3.2 Pengembangan Hipotesis

Setiap hipotesis mengikuti urutan:

**Claim → Theoretical mechanism → Empirical evidence → Counter/mixed evidence → Qualification → Hypothesis.**

Untuk model Dodo, substantive hypothesis set diarahkan pada:

- X1 → Z;
- X2 → Z;
- X1 → Y;
- X2 → Y;
- Z → Y;
- X1 → Z → Y;
- X2 → Z → Y.

Legacy "simultaneous effects" tidak otomatis ditempatkan sebagai hipotesis substantif utama.
