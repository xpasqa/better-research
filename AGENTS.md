# Agent Instructions

Instruksi kerja utama untuk repository ini berada di [`AGENT.md`](AGENT.md).

Gunakan `AGENT.md` sebagai workflow resmi untuk:

- struktur workspace disertasi;
- naskah Markdown kanonik;
- GitHub Issue, branch, commit, Pull Request, review, dan merge;
- literature review, data, analisis, export, dan revision log;
- aturan AI agent agar tidak mengarang referensi, evidence, atau citation.

Catatan penting: PR tidak boleh di-merge oleh agent tanpa instruksi eksplisit dari user.
