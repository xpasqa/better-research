# Naskah kanonik

Belum ada bab substantif. Susunan mengikuti pertanyaan, desain, dan pedoman kampus setelah project brief terisi.

Pilihan kerangka awal: pendahuluan; perdebatan literatur/teori; metodologi; temuan; pembahasan; simpulan. Kerangka ini boleh berubah untuk disertasi berbasis artikel, studi konseptual, etnografi, atau desain lain.

Gunakan Markdown sebagai sumber utama, nama berkas berurutan setelah outline diputuskan, serta istilah yang konsisten. Jangan membuat abstrak hasil atau kesimpulan empiris sebelum hasil tersedia.

Sitasi kerja dapat memakai citation key dari references.bib, misalnya sintaks `[@citation-key]`; contoh sintaks ini bukan referensi nyata. Style dan mesin ekspor belum dikonfigurasi. Setelah dikonfigurasi, periksa kecocokan sitasi–bibliografi dan tampilan hasil.

Gunakan [chapter plan](../templates/chapter-plan.md) sebelum menulis bagian besar.
