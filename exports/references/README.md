# Exported References

Folder ini digunakan untuk menyimpan export referensi disertasi Gemma, misalnya BibTeX, RIS, atau CSL JSON.

Catatan:

- Export bukan sumber kanonik.
- Sumber kanonik tetap `literature/references.bib`.
- Setiap export harus mencatat tanggal dan commit sumber jika sudah digunakan untuk penyerahan formal.
